##Task9- Laundary Services Button Interative (Transforms)


##Description:
Applied using the ":hover" pseudo-class to trigger changes when the cursor moves over the button.

-Used scale(1.2) inside the transform property to increses the button size.

-Used rotate(-10deg) inside the transform property to rotate the button.

-Both scaling and tilting transform are combined into a single CSS line.


 ##How to Run:
-Open the project folder in VS Code.

-Right click on index.html.

-Click "Open with Live Server".

-Click the Book-Button.
